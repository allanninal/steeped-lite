== Description ==

A calm, elegant block theme for tea rooms and tea shops. Patterns for a hero, house favourites, the full tea list by cup or pot with tasting notes and brewing times, afternoon tea sets, a gallery, your story, bookings and opening hours, all editable in the Site Editor.

Steeped Lite is a block theme: every page, header and footer is edited in the Site Editor, with no page builder. The front page is built from patterns you can rearrange, and each section is also in the pattern inserter for any page.

A contact form is plugin territory: for a form on your contact page, install a form plugin from WordPress.org.

The full version of Steeped adds a one-click demo import (pages, menu, photos and journal posts), a WooCommerce shop set up with products and photos, a dark style and a setup guide: https://checkout.freemius.com/theme/43140/plan/75183/

== Frequently Asked Questions ==

= Does the theme collect any data? =

No. Steeped Lite sets no cookies and uses no tracking. To offer updates it asks GitHub (api.github.com) for the latest release of github.com/allanninal/steeped-lite, at most twice a day; that request carries nothing about your site. The upgrade notice in the dashboard is a plain link; dismissing it is stored on your own site.

= How do I update it? =

Like any theme: new versions appear under Dashboard › Updates. Each version is also a release at https://github.com/allanninal/steeped-lite/releases, with the theme zip attached. Install that zip, not GitHub's "Source code" download, whose folder name is different.
