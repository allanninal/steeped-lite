# Steeped Lite

The free edition of **Steeped**, a WordPress block theme by [Allan Niñal](https://www.allanninal.dev/).
Every page, header and footer is edited in the Site Editor; the sections are block patterns.

- Theme page, demo and the full version: https://www.allanninal.dev/templates/themes/steeped/
- The same design as plain HTML: https://github.com/allanninal/steeped-html

## Install

Download **`steeped-lite-<version>.zip`** from the [latest release](https://github.com/allanninal/steeped-lite/releases/latest)
and upload it at Appearance › Themes › Add New › Upload Theme. Use that zip, not GitHub's
"Source code" download: its folder name is different, and updates would not find the theme.

## Updates

New versions appear under Dashboard › Updates, like any theme. The theme asks this repo's latest
release from api.github.com at most twice a day; the request carries nothing about your site.

## Free and full version

This edition has the whole design: every pattern, page template, header and footer, the light
style, the live open-now line and the menu board. The full version adds a one-click demo import,
a WooCommerce shop with products and order-ahead pickup, a dark style, a setup guide and support.
